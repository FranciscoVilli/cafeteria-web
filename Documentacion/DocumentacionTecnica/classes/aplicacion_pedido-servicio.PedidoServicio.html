    confirmarPedido

    • confirmarPedido(carrito: Carrito, codigoCliente: string): Promise<Pedido>

      Confirma el carrito como un pedido PENDIENTE (HU-04). Revalida la disponibilidad (SUP-07), toma el precio vigente (SUP-05), genera un código no usado (hasta MAX_INTENTOS_CODIGO intentos) y guarda cabecera y líneas en una transacción. Si al guardar otro pedido simultáneo tomó el mismo código, repite con otro (diseño 8.2).

      Parameters

      • carrito: Carrito
      • codigoCliente: string

      Returns Promise<Pedido>

      Throws

      Lanza PedidoVacioError si el carrito no tiene productos (RN-NEG-01)

      Throws

      Lanza ProductoNoDisponibleError si algún producto no está disponible (RN-NEG-02)

      Throws

      Lanza EntidadNoEncontradaError si el cliente o un producto no existe

      Throws

      Lanza PersistenciaError si no se pudo guardar

      • Defined in lib/aplicacion/pedido-servicio.ts:166
